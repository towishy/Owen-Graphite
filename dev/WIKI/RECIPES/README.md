# Change Recipes

Use recipes for common theme requests. Each recipe starts with WIKI routing, identifies the owner, lists evidence, and names the minimum gates.

| Request | Recipe |
| --- | --- |
| Reading heading spacing | `reading-heading-spacing.md` |
| Live Preview spacing/hit routing | `live-preview-spacing.md` |
| Rendered table polish | `rendered-table-polish.md` |
| PDF labels and presets | `pdf-label-preset.md` |
| Top chrome active/hover state | `top-chrome-state.md` |
| Style Settings option | `style-settings-option.md` |

If a request does not match a recipe, use `OWNER-DECISION-TREE.md` and add a recipe after the owner route is clear.
