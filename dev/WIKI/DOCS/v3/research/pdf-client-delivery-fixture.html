Client Delivery PDF

고객 전달용 검토 보고서

이 샘플은 고객에게 메일이나 Teams로 전달되는 PDF를 기준으로 구성했습니다. 본문은 화면에서 바로 읽히도록 조금 크게 잡고, 표와 callout은 낮은 대비 장식을 줄여 핵심 정보가 먼저 보이도록 조정합니다.

외부 링크는 본문 뒤에 긴 URL을 붙이지 않고, 문서 하단의 참고 목록으로 분리합니다. 본문 흐름을 깨지 않으면서도 출처 추적이 가능해야 하기 때문입니다.

요약

새 프리셋은 `ogd-pdf-client-delivery` 하나로 본문 크기, 제목 위계, 표 대비, callout 구분, 링크 출력 방식을 고객 전달용 톤에 맞춥니다.

검토 범위

영역 고객에게 보여야 하는 상태 프리셋 처리
본문 PDF 뷰어 100% 배율에서 확대 없이 읽힘 12.4pt 기반 크기와 1.48 줄간격
표 헤더와 셀 경계가 화면 캡처 후에도 구분됨 테두리와 헤더 대비 강화, 줄바꿈 안정화
링크 본문 흐름은 깨지지 않고 출처는 별도 확인 가능 본문 inline URL 숨김, reference block 중심 정리
콜아웃 요약, 위험, 권장 항목이 인쇄 후에도 빠르게 구분됨 상단 accent bar와 밝은 배경 톤 적용

상태 요약

주의

문서에 매우 넓은 표가 많으면 표마다 `print-fit-table` 또는 `wrap-table`을 지정해야 합니다. 프리셋은 기본 가시성을 높이지만 콘텐츠 구조 자체를 추측해서 바꾸지는 않습니다.
