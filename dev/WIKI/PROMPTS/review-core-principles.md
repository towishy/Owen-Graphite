# Prompt: Review Core Principles

Before finalizing a change, verify:

- No `src/polish` reintroduction.
- No `!important`.
- No `.cm-table-widget` or `table.cm-table` theme geometry.
- No generic LP table selector without `:not(.cm-table-widget):not(.cm-table)`.
- No late repair when owner code should change.
- Source usage map is fresh.
- Core principles gate passes.
