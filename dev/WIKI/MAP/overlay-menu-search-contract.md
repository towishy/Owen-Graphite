# Risk Contract: Overlay Menu Search

Applies to command palette, menus, suggestions, popovers, tooltips, modals, and search UI.

## Owners

- Overlay and Dataview presentation: `src/chrome/32-overlay-popover-dataview.css`.
- Editing toolbar and tooltips: `src/chrome/35-editing-menu-tooltip-glass.css`.
- Floating UI surfaces and shared overlay glass: `src/chrome/36-floating-ui-glass-system.css`.

## Boundaries

- Do not treat overlay/menu/search as workspace chrome unless the selector is also a workspace shell selector.
- Owen Graphite owns the outer Glass boundary of `.owen-editor-palette-modal`, while Owen Editor owns its internal command canvas and `.owen-editor-search`; generic theme modal-control selectors must exclude that plugin-owned search input in resting and focused states.
- Search result rows must not change height across hover, focus, or active states.
- UI cards, widgets, popups, and notices must not combine rounded corners with a vertical left accent rail (`border-left` / `border-inline-start`). Rounded surfaces remain allowed; the prohibited pattern is the accent line attached to the rounded edge.
- If the state is generated by Obsidian runtime classes or inline style, collect runtime DOM/computed evidence first.

## Evidence

- Capture at least one resting state and one focused/hovered/selected state for interaction fixes.
- Record the matched theme rule and source owner in `dev/TEMP/runtime-evidence` before changing state behavior.
