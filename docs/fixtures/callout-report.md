# Owen Graphite Callout Report Fixture

이 문서는 보고서형 callout 팔레트의 Reading View, Live Preview, PDF Export 회귀 확인용 샘플입니다.

> [!conclusion] 권장 결론
> 최종 판단이나 제안 텍스트를 짧고 단정하게 강조합니다.

> [!recommendation] 권장 조치
> 실행 가능한 권장안을 담당자와 후속 일정에 연결합니다.

> [!risk] 주의
> 정책 충돌, 우회 가능성, 운영 위험을 명확히 드러냅니다.

> [!action] 다음 단계
> 바로 수행해야 하는 작업을 체크리스트처럼 정리합니다.

> [!decision] 결정 사항
> 회의 또는 설계 결정의 확정 내용을 기록합니다.
