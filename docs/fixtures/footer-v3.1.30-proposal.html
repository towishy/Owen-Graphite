구현 메커니즘 (3안 공통)

@media print {
  /* abs containing-block 보장 */
  body, .markdown-preview-view, .markdown-preview-sizer, .markdown-rendered { position: relative; }

  /* :last-child reserve */
  body.ogd-last-page-footer .markdown-rendered > :last-child {
    position: relative !important;
    margin-bottom: 80mm !important;
  }

  /* LABEL  — :last-child::before  (단일 string)            */
  body.ogd-last-page-footer .markdown-rendered > :last-child::before {
    content: var(--ogd-last-page-footer-label, "") !important;
    /* abs, top, font-size, color … 단일 형식만 */
  }

  /* TITLE  — :last-child::after   (단일 string, ::first-line 없음) */
  body.ogd-last-page-footer .markdown-rendered > :last-child::after {
    content: var(--ogd-last-page-footer-title, "") !important;
    /* abs, top, 큰 font-size, dark color … 단일 형식만 */
  }

  /* BODY   — sizer::after          (페이지 1 헤더와 충돌 안 하는 free anchor) */
  body.ogd-last-page-footer .markdown-preview-sizer::after {
    content: var(--ogd-last-page-footer-body, "") !important;
    /* abs, 좌측 정렬, 작은 font-size, medium gray, line-height 1.5 … 단일 형식만 */
  }
}

핵심 — 각 pseudo는 단일 var() 단일 형식만. 페이지 1 헤더가 4-slot 정상 작동으로 이 패턴이 Chromium PDF에서 보장됨을 이미 증명.
