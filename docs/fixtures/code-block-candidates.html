권장

C (Frosted Glass + Rim) 를 메인으로, D (Minimal Outlined)를 인쇄/PDF용 보조로 채택 권장. C는 Owen Graphite의 Glass+Shadow 언어와 완전 일치하고, 상단 헤더 row(lang pill + copy)로 inline → fenced 전환을 시각적으로 명확히 합니다. D는 `body.ogd-pdf-compact` 또는 print 미디어에서만 적용해 잉크/지면을 아끼고 본문 가독성을 유지합니다.

승인하시면 다음 patch로 진행:
1) dev/03a-reading-tables-code.css에 C 스타일 fenced code block 룰 추가 (Reading)
2) dev/05-live-preview.css에 동일 톤 LP fenced 코드 룰 추가 — 주의: .HyperMD-codeblock cm-line에는 vertical padding 금지(hit-routing contract)
3) dev/08-report-print-polish.css @print 영역에 D 스타일 폴백
4) scripts/diff_guard.py + validate_theme.py가 hit-routing 위반 자동 차단
