외부 링크 점선 밑줄 색상 샘플

외부 URL은 본문 링크와 구분되도록 점선 밑줄을 사용합니다. 본문 읽기 흐름을 해치지 않는 회색/청색/틸 계열을 중심으로, 보고서 문서에서 쓸 수 있는 후보를 비교했습니다.

01 Slate Graphite

보고서 본문에서는 Microsoft Learn 외부 링크가 색으로 튀지 않고 문장 안에 조용히 머뭅니다.

가장 graphite 테마다운 후보이며 PDF 출력에서도 안정적입니다.

#334155 / #94a3b8

02 Classic Blue

전통적인 웹 링크처럼 GitHub 외부 링크를 즉시 알아볼 수 있습니다.

인지성은 가장 높지만 보고서 전체 톤에서는 약간 선명합니다.

#1d4ed8 / #93c5fd

03 Muted Teal

기술 문서의 참조 URL인 Azure 외부 링크를 차분하게 강조합니다.

정보성, 현대감, 보고서 톤 사이의 균형이 좋아 추천 후보입니다.

#0f766e / #5eead4

04 Indigo

제품 문서나 개발 문맥의 VS Code 외부 링크가 세련되게 보입니다.

청색보다 부드럽지만 색 인상이 조금 강합니다.

#4338ca / #a5b4fc

05 Violet

Obsidian 생태계의 Obsidian 외부 링크와 잘 어울립니다.

브랜드 느낌은 좋지만 긴 보고서에서는 장식감이 느껴질 수 있습니다.

#6d28d9 / #c4b5fd

06 Amber

주의성 참조인 관리 포털 외부 링크를 강조할 때 어울립니다.

일반 링크보다는 경고/주의 링크용으로 적합합니다.

#92400e / #fcd34d

07 Rose

보안 위험 참조인 MSRC 외부 링크를 강하게 구분합니다.

일반 외부 링크보다는 취약점/위험 링크에 한정하는 편이 좋습니다.

#be123c / #fda4af

08 Green

완료 상태나 검증 문서의 상태 페이지 외부 링크에 자연스럽습니다.

success 의미와 겹칠 수 있어 일반 링크에는 신중한 후보입니다.

#047857 / #86efac

09 Monochrome

출력물 중심 문서에서는 외부 링크 주소도 거의 본문처럼 보입니다.

가장 절제되어 있지만 링크 인지성은 낮습니다.

#111827 / #cbd5e1

Dark mode 후보

Dark Blue: 외부 문서 링크가 가장 익숙하고 식별성이 높습니다.
Dark Teal: 외부 문서 링크가 modern하면서도 피로도가 낮습니다.
Dark Slate: 외부 문서 링크가 보고서 톤에 가장 조용히 녹습니다.
