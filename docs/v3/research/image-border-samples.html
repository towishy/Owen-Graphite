이미지 외곽라인 샘플

문서에 첨부하거나 삽입한 이미지를 본문 배경과 분리하기 위한 1px 회색계열 외곽라인 후보입니다. 기본 적용안은 첫 번째 샘플입니다.

추천안 A: 기본 faint gray

본문 이미지 기본값. 흰 배경 스크린샷과 문서 배경을 부드럽게 구분합니다.

샘플 B: 더 연한 outline

이미지 자체가 복잡하거나 테두리가 이미 있는 경우에 적합합니다.

샘플 C: 조금 더 선명한 gray

밝은 페이지에서 스크린샷 경계가 자주 사라질 때 좋지만, 기본값보다 약간 더 강합니다.

샘플 D: 내부 hairline

레이아웃 치수 증가가 싫을 때 쓰는 방식입니다. 이번 기본 구현은 더 예측 가능한 border-box를 사용했습니다.
